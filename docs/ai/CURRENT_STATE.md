## Como abrir a aplicação

Na raiz do repositório, em um terminal, aplique as migrations locais e inicie o Worker (a configuração `.dev.vars` já foi preparada neste checkout; se o arquivo não existir após uma nova instalação, siga [apps/api/README.md](../../apps/api/README.md)):

```sh
pnpm --filter @marcia/api db:migrate:local
pnpm --filter @marcia/api dev
```

Em outro terminal, abra Expo Web:

```sh
EXPO_PUBLIC_API_URL=http://127.0.0.1:8787 pnpm --filter @marcia/mobile web
```

Abra `http://127.0.0.1:8081` no navegador para manter o mesmo host da API. Para o fluxo privado, conclua o setup do primeiro owner com um token local; a configuração está descrita no README da API. Para Android, configure a URL de API como `http://10.0.2.2:8787` no emulador padrão. Não use os placeholders do exemplo como secrets de produção.
